## Лабораторная работа №6: Generics и typing

В данной лабораторной работе изучается система аннотаций типов в Python, а также использование обобщённых типов (Generics) и структурной типизации через Protocol.

Рассматриваются:
- аннотации типов
- Generic-классы
- TypeVar
- функции с типами (Callable)
- Protocol (структурная типизация)

---

## Реализованные типы и коллекции

### Типизированная коллекция

Реализован обобщённый класс `TypedCollection`, который является универсальной коллекцией и может работать с любым типом данных.

Используется TypeVar:

- `T` — тип элементов коллекции
- `R` — тип результата при преобразовании (в методе map)

Коллекция поддерживает:
- добавление элементов
- удаление элементов
- получение всех элементов

---

### Методы обработки коллекции

Добавлены методы:

- `find` — поиск элемента по условию
- `filter` — фильтрация элементов
- `map` — преобразование элементов

Метод `map` позволяет изменять тип результата, что демонстрирует использование второго TypeVar (`R`).

---

### Protocol (структурная типизация)

Реализованы два протокола:

- `Displayable` — объект должен иметь метод `display()`
- `Scorable` — объект должен иметь метод `score()`

Протоколы задают требования к объектам без необходимости наследования.

---

### Ограниченные типы

Используются ограниченные TypeVar:

- `D` — только объекты с методом `display()`
- `S` — только объекты с методом `score()`

На их основе реализованы специализированные коллекции:

- `DisplayCollection` — работает с объектами, у которых есть `display()`
- `ScoreCollection` — работает с объектами, у которых есть `score()`

Это позволяет безопасно вызывать соответствующие методы внутри коллекции.
