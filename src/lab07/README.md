# ЛР-7 — Консольное приложение

---

## Цель работы

* Объединить все знания, полученные в ЛР1–ЛР6, в единое работающее приложение.
* Реализовать интерактивный CLI-интерфейс с меню и вводом пользователя.
* Реализовать сохранение и загрузку данных через JSON.
* Применить модульную архитектуру и обработку исключений.


## Описание CLI

В приложении реализовано интерактивное меню:

```text
1. Добавить городской автобус
2. Добавить туристический автобус
3. Добавить электробус
4. Показать все автобусы
5. Найти автобус по ID
6. Удалить автобус
7. Фильтр по скорости
8. Сортировка
0. Выход
```

Программа работает циклически:
после выполнения операции меню отображается повторно.

---

### Обработка ошибок

Обрабатываются:
* неверный ввод чисел
* ввод строки вместо числа
* поиск несуществующего автобуса
* добавление дубликатов
* ошибки чтения JSON

Используются собственные исключения:

```python
class BusError(Exception):
    pass

class BusNotFoundError(BusError):
    pass

class DuplicateBusError(BusError):
    pass
```

---

### Сохранение и загрузка данных

При запуске программы автоматически выполняется загрузка данных из:

```text
buses.json
```

После изменения коллекции данные автоматически сохраняются в JSON-файл.

---

## Реализованные возможности

### Работа с коллекцией

Поддерживаются операции:
* добавление объектов
* удаление объектов
* поиск по ID
* вывод коллекции

---

### Фильтрация

Реализована фильтрация автобусов:
* по минимальной скорости

Используются lambda-функции.

---

### Сортировка

Реализована сортировка:
* по скорости
* по вместимости
* по имени водителя

Сортировка реализована через передачу функций как стратегий.

---

### Сериализация

Реализовано:
* преобразование объектов в словари
* сохранение JSON
* восстановление объектов из JSON

Поддерживаются:
* CityBus
* TouristBus
* ElectricBus
